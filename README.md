🎬 AMmovies - Cinematic Discovery Dashboard
A sleek, high-performance React application that allows users to discover movies and TV shows using the TMDB API. This project features dynamic genre filtering, a "Top 10" trending sidebar, and integrated YouTube trailer playback.

✨ Features
Dual Mode Discovery: Seamlessly switch between Movies and TV Series with context-aware data fetching.

Dynamic Genre Filtering: Filter content by genre specific to the media type (e.g., "Action" for movies vs. "Action & Adventure" for TV).

Global Search: A responsive search bar in the Navbar and Hero section for finding specific titles across the platform.

Top 10 Trending Sidebar: A "sticky" sidebar highlighting the week's most popular content with rankings and ratings.

Integrated Trailer Modal: Watch official movie/TV trailers directly within the app via a YouTube iFrame modal.

Fully Responsive Design: A cinematic UI that adapts from 4-column desktop grids to mobile-friendly layouts.

🚀 Tech Stack
Frontend: React 18

Routing: React Router v6

API Client: Axios

Data Source: The Movie Database (TMDB)

Styling: Custom CSS3 (Flexbox & Grid)
